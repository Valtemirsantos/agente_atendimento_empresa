# Diretrizes do projeto

- Nunca registre chaves, senhas, cartoes ou documentos completos em logs, testes ou commits.
- Mantenha segredos apenas no arquivo `.env`, que nao deve ser versionado.
- As ferramentas do agente devem consultar somente os dados necessarios para responder.
- Encaminhe cancelamentos, reembolsos, reclamacoes e solicitacoes com dados pessoais para uma pessoa atendente.
- Execute os testes antes de enviar alteracoes ao repositorio.
